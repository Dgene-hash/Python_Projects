# Expense Tracker

A beginner-friendly Python project to manage and analyze daily expenses.

## Features
- Collects expense amounts and categories.
- Validates user input.
- Calculates total, highest, lowest, and average expenses.
- Checks expenses against a monthly budget.
- Searches expenses by category.

## Concepts Used
- Python Functions
- Lists and Nested Lists
- Loops (`while`, `for`)
- Conditional Statements
- Input Validation
- Return Values

## Language
Python
